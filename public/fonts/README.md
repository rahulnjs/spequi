# Bundled fonts

DM Sans (variable weights 400–700) and IBM Plex Mono (weights 400 and 500), normal style, are distributed under the SIL Open Font License 1.1. See `dm-sans-OFL.txt` and `ibm-plex-mono-OFL.txt`.

Downloaded from the official Google Fonts CSS API on 2026-11-10. The stylesheet retains the supplied Unicode subsets and uses only local URLs. No download or font build step is needed at installation or runtime.

Source stylesheet: https://fonts.googleapis.com/css2?family=DM+Sans:wght@400..700&family=IBM+Plex+Mono:wght@400;500&display=swap
